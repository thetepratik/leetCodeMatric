# LeetCode Matrix

LeetCode Matrix is a web-based application that fetches and displays LeetCode user statistics using the LeetCode username.

## 📌 Project Description
This project allows users to enter their **LeetCode username**, and the application automatically fetches and shows relevant LeetCode data such as problem-solving statistics.  
It is designed to help users quickly analyze their LeetCode performance in a clean and simple interface.

## 🛠️ Technologies Used
- **HTML** – Structure of the web application  
- **CSS** – Styling and layout  
- **JavaScript** – Fetching LeetCode data and dynamic updates  

## 🚀 Features
- User-friendly interface  
- Fetches LeetCode data using username  
- Displays statistics dynamically  
- Lightweight and fast  

## 📂 Project Structure
- `leetmatric.html` – Main HTML file  
- `style.css` – Styling  
- `script.js` – Logic to fetch and display LeetCode data
